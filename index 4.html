    🐙 GitHub-Speicher

    So verbindest du die Seite mit deinem Repository
    1. Auf GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Bei Repository access nur dieses eine Repository auswählen.
    3. Bei Permissions → Repository permissions den Eintrag Contents auf Read and write setzen.
    4. Token erzeugen, kopieren und unten einfügen. Er wird nur in diesem Browser gespeichert – nie in der Seite oder im Repository.
